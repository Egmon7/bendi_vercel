# BusConnect

Plateforme de réservation de voyages interurbains en RDC.

BusConnect digitalise le transport interurbain en permettant aux voyageurs de réserver leurs billets de bus directement depuis leur téléphone, sans se déplacer en agence.

## Objectif

Faciliter les réservations, moderniser le transport et centraliser les informations de voyage entre voyageurs, agences de transport et administrateurs de la plateforme.

## Lancement

Le projet démarre sur l'axe **Kinshasa ↔ Matadi**, puis évoluera vers d'autres villes, la gestion des colis et la logistique.

## Rôles

- **Administrateurs** — gestion globale de la plateforme (agences, utilisateurs, réservations, finances, statistiques)
- **Agences partenaires** — gestion de leurs trajets, réservations et clients
- **Clients / voyageurs** — recherche, réservation et suivi de leurs billets

## Stack

- Next.js
- React
- Tailwind CSS

Phase actuelle : frontend uniquement.
